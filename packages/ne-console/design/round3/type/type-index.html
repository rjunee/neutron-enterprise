Round 3 — the type bake-off

Owner feedback on the chosen direction: the typeface is "a bit harsh and needs to feel a bit smoother." Every card below re-renders the same round-2 Approvals screen with the typeface as the only variable (UI candidates hold JetBrains Mono; mono candidates hold Source Sans 3). Thumbnails are the dense table region, dark theme at 2x. Full renders and per-candidate specimens (scale, numerals, measured tabular-figure support, ambiguity traps) are linked on each card. Byte figures are pinned latin woff2 totals from fonts.json.

Recommendation — Source Sans 3 (400/500/600/700) + Fira Mono (400/500/700). 113,728 bytes of latin woff2 against today's 162,540-byte budget — 30% headroom. Humanist, smooth, tabular figures by default in the sans, marked zero and distinct Il1| in the mono, both OFL-1.1 from pinned @fontsource packages vendorable through the existing scripts/vendor-fonts.mjs pattern (out of the npm closure, zero runtime requests). UI CANDIDATE — RECOMMENDED

Source Sans 3

62,612 B

Winner. Humanist bowls and open apertures soften the 13.5px cells without a hint of startup-friendly; 11px labels stay quiet; default figures are tabular (measured) so every count and timer aligns even without tnum; holds both themes.

full render · specimen · @fontsource/source-sans-3@5.3.0 · OFL-1.1

UI CANDIDATE — RUNNER-UP

Hanken Grotesk

54,880 B

Close second: warmer and rounder, tabular by default too. Lost on the louder large x-height in dense tables, the busy foot-serif ‘1’ in timers/dates, and a drift toward friendly-UI-kit.

full render · specimen · @fontsource/hanken-grotesk@5.3.0 · OFL-1.1

UI CANDIDATE

Plus Jakarta Sans

48,560 B

Smoother but geometric-soft/brand-y — the startup-playful failure mode. I/l identical at 12.5px; default figures proportional (measured 200.3 vs 395.3), so any span missing tnum misaligns.

full render · specimen · @fontsource/plus-jakarta-sans@5.3.0 · OFL-1.1

UI CANDIDATE

Inter

96,744 B

The neutral control. Better spacing than Plex but terminals stay blunt — it does not deliver ‘smoother/warmer’. Proportional default figures; heaviest candidate.

Fira Mono

51,116 B

Winner, shown paired with Source Sans 3 (this render IS the recommended pairing). Rounded humanist terminals take the stiffness out of write.internal.notes.append at 13px; marked zero, distinct Il1|; real 400/500/700.

MONO CANDIDATE

Geist Mono

30,160 B

Byte-cost winner (30 KB for three weights) and clean, but cooler and more geometric — it modernizes rather than warms. The fallback if budget ever tightens.

MONO CANDIDATE

Commit Mono

143,352 B

Pleasant, deliberately neutral — but ~48 KB per weight; the pairing total hits 205,964 B, 27% over the 162 KB budget. Disqualified on byte cost.

full render · specimen · @fontsource/commit-mono@5.3.0 · OFL-1.1

Method notes: judged from screenshots read back at the sizes that matter (13.5px cells, 11px uppercase labels, 14px body, 13px mono identifiers like write.internal.notes.append), in both themes for the finalists. Tabular-figure support was measured in-page (width of 1111 vs 0000, with and without font-variant-numeric), not assumed: Source Sans 3 and Hanken Grotesk are tabular by default; Inter and Plus Jakarta Sans are proportional by default with tnum available; all three monos are monospaced by construction. DM Mono was excluded before rendering — the package has no 700 weight and the screen uses mono 700. IBM Plex Mono was not re-run: it shares the Plex family's blunt terminals, which is the harshness being removed.
