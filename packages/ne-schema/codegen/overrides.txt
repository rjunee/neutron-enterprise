# `jsonschema[format-nongpl]` so the codegen env contains ZERO GPL distributions

# env never enters the platform lock. Pinned + hashed so it is usable both in
# `uv pip compile` and `uv pip install --require-hashes` (which require every
# override to be ==-pinned and hashed). Hashes match jsonschema==4.26.0 in
# requirements.txt.
